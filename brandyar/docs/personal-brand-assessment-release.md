## تغییرات واقعی این انتشار

- پنج مرحله با عنوان و شماره، نوار پیشرفت مراحل ثبت‌شده، بازگشت، ذخیرهٔ پیش‌نویس همان تب و ذخیرهٔ قطعی هر مرحله روی سرور.
- مرحلهٔ اول مطابق متن درخواست: تخصص، هشت وضعیت حرفه‌ای، نه هدف، مخاطب، مسئله و ده مانع با الزام انتخاب یک تا دو مورد؛ تخصص ورودی کوتاه و وضعیت/هدف انتخابی‌اند.
- شش پرسش هویت و جایگاه با الزامی‌بودن پنج مورد و اختیاری‌بودن مخاطب نامناسب؛ بدون سؤال بیو.
- دقیقاً ۲۴ گویهٔ درخواست‌شده، چهار گویه برای هر بُعد، با پنج گزینهٔ قابل لمس؛ کلید، بُعد، وزن، ترتیب و وضعیت نمایش نسخه‌دارند. تطابق کامل منبع با قالب منتشرشدهٔ دیتابیس زنده بررسی شد؛ ۱۲۰ گزینهٔ طیف پنج‌درجه‌ای ثبت شده‌اند.
- هفت فیلد شواهد اختیاری، محدودیت طول، شمارنده، نمایش escape‌شده و کنترل لینک HTTPS.
- مرحلهٔ پنجم اختیاری با دو مسیر اتصال/ادامه بدون اتصال؛ معرفی دستی فقط پس از انتخاب ادامه بدون اتصال ظاهر می‌شود. وضعیت فعلی اتصال «نیازمند تکمیل تنظیمات» است؛ موفقیت جعلی نمایش داده نمی‌شود.
- نمرهٔ هر بُعد از گویه‌های فعال همان نسخه محاسبه می‌شود: میانگین وزنی `(پاسخ−۱)×۲۵`. وزن فعلی گویه‌ها یک و وزن ابعاد یک‌ششم است. دادهٔ ناقص گزارش نهایی نمی‌سازد.
- بلوغ علاوه بر میانگین، محدودیت ناشی از کمبود ابعاد اصلی را لحاظ می‌کند. الگوی اصلی و حداکثر دو الگوی فرعی از ترکیب هدف، وضعیت حرفه‌ای، نمره‌ها و شواهد پیشنهادی استخراج می‌شوند؛ تصادفی نیستند و تشخیص شخصیت نیستند.
- گزارش بازطراحی‌شده شامل خلاصهٔ شخصی، شش نمره، رفتارهای قوی‌تر و نیازمند توجه، پیام پیشنهادی، چرایی الگو، سه اقدام فوری و سه اقدام میان‌مدت با زمینهٔ پاسخ‌های کاربر، وضعیت اتصال و دریافت HTML است.
- ویرایش پاسخ‌ها و تولید نسخهٔ جدید گزارش ممکن است؛ نسخهٔ گزارش قبلی تغییر نمی‌کند.
- مدیریت، نسخه/مرحله/زمان/وضعیت تحلیل و اتصال را نمایش می‌دهد. جزئیات دارای بخش‌های پاسخ، نمره و نتیجه، شواهد، Instagram و تاریخچهٔ اجرا/خطا/حسابرسی است. ویرایش متن، ترتیب و فعال‌بودن سؤال، پیش‌نویس مستقل می‌سازد؛ انتشار و بازتحلیل نیازمند نقش مجاز، دلیل و تأیید هستند.
- کنترل مالکیت نشست، نقش‌های مدیریت، CSRF، رمزنگاری توکن، state یک‌بارمصرف، قطع اتصال، حذف داده و رویدادهای محصول موجود حفظ شده‌اند. تکمیل ارزیابی و اجرای تحلیل نیز ثبت می‌شوند.

## migration و استقرار

- migration شمارهٔ ۱ در انتشار قبلی اجرا شده بود؛ در این انتشار تغییر داده نشد.
- `personal_brand_migration_002.sql` روی دیتابیس تولید اجرا شد: جدول افزایشی `pb_question_rules` برای وزن/فعال‌بودن و `pb_analysis_runs` برای وضعیت تحلیل با محدودیت یک اجرای running برای هر ارزیابی.
- قالب تازه با شناسهٔ `pb-test-24-v2` و مدل `pb-score-rules-v2` منتشر شدند. موتور جدید `structured-rules-v2` است. بدنهٔ قالب‌ها و نتایج قبلی بازنویسی نشدند؛ نسخه‌های منتشرشدهٔ قدیمی برای شروع‌های تازه غیرفعال شدند.
- قبل از انتشار، تطابق فایل‌های قبلی با مبنای شناخته‌شده بررسی و پشتیبان سازگار SQLite و کد قبلی با دسترسی محدود تهیه شد. migration در توقف کوتاه سرویس و پیش از فعال‌شدن کد جدید انجام شد.
- `quick_check` و `foreign_key_check` موفق بودند. شمار رکوردهای کاربران، staff، مشاوره‌ها، لیدها، ارزیابی‌ها، پاسخ‌ها، گزارش‌ها، نمره‌ها، شواهد، اتصال‌ها و audit پیش و پس از migration حفظ شد.
- همهٔ فایل‌های runtime تغییرکردهٔ زنده با فایل‌های نسخهٔ آزمایش‌شده تطبیق داده شدند. سرویس پس از انتشار active بود. هیچ کاربر، پیج یا نتیجهٔ آزمایشی در دیتابیس تولید ایجاد نشد.

## آزمون‌های انجام‌شده

- ۱۴۰ اجرای تست Python در محیط محلی و مجدداً روی Python سرور با موفقیت؛ پایگاه‌های تست موقت بودند.
- سه مجموعهٔ Node: ارزیابی قبلی، پنل قبلی و ماژول جدید، موفق بودند. پوشش ماژول جدید شامل نمایش همهٔ ۲۴ متن، ۱۲۰ گزینه، ذخیرهٔ آرایهٔ موانع، پنج مرحله، معرفی شرطی، تولید گزارش، escape، لغو و محدودیت نقش است.
- آزمون migration از ساختار شمارهٔ ۱، حفظ دقیق بدنهٔ قالب، پاسخ و گزارش قبلی را تأیید کرد. شروع جدید نسخهٔ ۲۴گویه‌ای می‌گیرد. ویرایش/ادامه، نتایج متفاوت با پاسخ‌های متفاوت، مالکیت، قطع اتصال و خطاهای OAuth نیز پوشش دارند.
- syntax سه فایل JavaScript تغییرکرده، `compileall` پایتون روی سرور و `git diff --check` موفق شدند. این پروژه HTML/JavaScript و Python استاندارد است؛ bundler یا مرحلهٔ build مبتنی بر Node/TypeScript ندارد.
- نه بررسی HTTPS پس از انتشار: صفحهٔ اصلی، ارزیابی، JS، CSS و ورود مدیر پاسخ ۲۰۰؛ مدیریت برای مهمان ۳۰۳؛ API مدیریت بدون ورود ۴۰۱؛ `/assessment` پاسخ ۳۰۳؛ bootstrap پاسخ ۲۰۰.
- تست مرورگر، بررسی بصری واقعی و ورود با حساب شخصی مدیر انجام نشده است. تست رابط با Node VM و بررسی مسیرها با HTTP انجام شده‌اند، نه مرورگر.

## تنظیمات لازم برای Meta

این نام‌ها باید در محیط امن سرویس تنظیم شوند؛ هیچ مقدار محرمانه‌ای در کد، چت یا گزارش ثبت نشده است:

| نام | کاربرد |
|---|---|
| `META_INSTAGRAM_APP_ID` | شناسهٔ اپ Instagram Login |
| `META_INSTAGRAM_APP_SECRET` | secret اپ، فقط سمت سرور |
| `META_INSTAGRAM_REDIRECT_URI` | آدرس دقیق `https://nesharo.ir/api/personal-brand/instagram/callback`؛ عیناً در allowlist اپ ثبت شود |
| `META_GRAPH_VERSION` | نسخهٔ پشتیبانی‌شدهٔ اپ با قالب `vN.N` |
| `PB_TOKEN_ENCRYPTION_KEY` | کلید استاندارد Fernet که مدیر امن زیرساخت تولید و نگهداری می‌کند |

کتابخانهٔ رمزنگاری روی سرور موجود و در آزمون‌ها استفاده شد؛ وابستگی سرور ارتقا نیافت. مجوز پیاده‌شده `instagram_business_basic` و حساب‌های مجاز Business/Creator هستند. app review/دسترسی لازم، تطبیق قرارداد زندهٔ فیلدها، تنظیم عدم ثبت query callback در proxy و آزمون grant واقعی پیش از فعال‌سازی عمومی لازم‌اند. راهنمای تکمیلی در `instagram-connection-setup.md` است.

## محدودیت‌های واقعی باقی‌مانده

- تنظیمات Meta فعلی کامل نیستند؛ اتصال واقعی یک حساب و دریافت دادهٔ زنده در این تحویل آزمایش نشده‌اند. حالت تنظیم‌شده با provider mock و حالت تنظیم‌نشده روی سایت زنده بررسی شده است.
- موتور تحلیل شفاف و rule-based است. تحلیل معنایی خودکار لحن/موضوع، تحلیل تصویر/ویدیو/صدا، insights، comments و refresh خودکار توکن پیاده نشده‌اند. Instagram فعلاً شواهد رسمی متن/فراداده می‌افزاید و نمرهٔ خوداظهاری را تعدیل نمی‌کند؛ فهرست تعدیل‌ها خالی و این موضوع در گزارش آشکار است. سطح «تحلیل کامل با داده‌های تأییدشدهٔ پیج» بدون آن شواهد صادر نمی‌شود.
- هویت عمومی به نشست امن همین مرورگر وابسته است؛ حساب دائمی، نام تأییدشده و بازیابی بین دستگاه‌ها وجود ندارد. نام ساختگی برای کاربر تولید نمی‌شود.
- callback امضاشدهٔ حذف Meta، پاک‌سازی زمان‌بندی‌شده و سیاست حقوقی حذف backup هنوز نهایی نشده‌اند؛ حذف دادهٔ درون محصول و ابزار maintenance موجودند.
- دو فایل لوگوی مشخص‌شده در درخواست در workspace موجود نبودند؛ لوگوی فعلی واقعی سایت استفاده شد.

بنابراین جایگزینی مسیر اصلی، سؤال‌های دقیق، ذخیره و گزارش نسخه‌دار و انتشار واقعی انجام شده‌اند؛ این گزارش، امکانات تحلیل پیشرفته یا تأیید بیرونی Meta را کامل‌شده اعلام نمی‌کند.
