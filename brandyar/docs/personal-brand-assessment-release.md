# تحویل ارزیابی پرسونال برند — نسخهٔ ۳ — ۲۰۲۶-۱۰-۲۷

## وضعیت انتشار

نسخهٔ `pb-test-15-v3` با مدل `pb-score-rules-v3` و موتور `structured-rules-v3` در سایت واقعی https://nesharo.ir/personal-brand فعال شد. این گزارش داخلی است و در رابط عمومی نمایش داده نمی‌شود.

## فایل‌های تغییرکرده

فایل‌های runtime منتشرشده:
- `personal-brand.html`: هدر و فوتر اصلی، sprite مشترک، تم سایت و حذف مسیر مدیریت عمومی.
- `personal-brand.css`: رنگ‌های وابسته به تم، کارت‌ها، فرم‌ها، نمودارها، فوکوس و قواعد موبایل.
- `personal-brand.js`: پنج بخش جدید، پیش‌نویس محلی و خودکار، ادامه، نتیجهٔ اولیه، لید، گزارش کامل، قطع اتصال و ابزار بازبینی مدیریت.
- `personal_brand.py`: نسخهٔ فعال جدید، ذخیرهٔ پاسخ ناقص، شروع تکراری ایمن، تأیید شروع دوباره، gate واقعی گزارش، رضایت و شماره، بازخورد سؤال و مدیریت.
- `personal_brand_model.py`: سؤال‌های جدید، validation نسخه‌دار، ۱۵ رفتار، پنج بُعد و نمره‌دهی واقعی؛ حفظ مدل‌های قدیمی.
- `personal_brand_maintenance.py`: حفاظت و پاک‌سازی وابستگی‌های جدید.
- `personal_brand_migration_003.sql`: جداول افزایشی لید، پاسخ ناقص و بازخورد وضوح.
- `personal_brand_question_catalog.py`: سازه، بُعد، دلیل و وضعیت نمره‌دهی همهٔ ۳۱ سؤال، نسخه و تاریخ.

تست‌های تغییرکرده: `test_personal_brand.py`، `test_personal_brand.cjs` و `test_personal_brand_v3.py`.

## مسیرها

- صفحهٔ اصلی ارزیابی: `/personal-brand`؛ تجربهٔ اصلی اکنون نسخهٔ جدید است.
- API عمومی: `/api/personal-brand`؛ پاسخ ناقص، شروع/ادامه، نتیجهٔ اولیه، ثبت رضایت و گزارش کامل واقعاً در این مسیر اجرا می‌شوند.
- مدیریت موجود: `/admin/personal-brand` و `/api/admin/personal-brand`؛ احراز هویت و نقش لازم است و از صفحهٔ عمومی لینکی ندارد.
- callback رسمی موجود: `/api/personal-brand/instagram/callback`.
- مسیر قدیمی `/assessment` و ارجاع‌های سایت حفظ شده‌اند؛ مسیر جدیدی به‌جای مسیر اصلی ساخته نشده است.

## قابلیت‌های تکمیل‌شده

- پنج بخش با ۵، ۵، ۱۵، ۳ و ۳ سؤال؛ بخش سوم دقیقاً متن‌های ۱۵گانهٔ درخواست‌شده و ۷۵ گزینهٔ طیف دارد.
- توضیح و هدف کوتاه هر بخش، پیشرفت، بازگشت و لمس مناسب؛ گزینه‌های «دیگر» و متن اختیاری/الزامی مربوطه؛ مخاطب حداکثر دو انتخاب و شواهد چندانتخابی.
- ذخیرهٔ محلی پایدار و ذخیرهٔ خودکار پاسخ ناقص در سرور؛ حفظ پاسخ هنگام بازگشت و خطای شبکه. شروع‌های تکراری یک draft را ادامه می‌دهند.
- شروع پس از تکمیل، نتیجهٔ موجود را برمی‌گرداند؛ ارزیابی تازه فقط با تأیید از نتیجه آغاز می‌شود. ویرایش عمومی مستقیم نتیجه مسدود است.
- میانگین واقعی `(پاسخ−۱)×۲۵` برای پنج بُعد با وزن پیش‌فرض برابر؛ زمینهٔ کاری امتیاز مصنوعی ایجاد نمی‌کند. آستانهٔ مرحله‌ها ۲۰، ۴۰، ۶۰ و ۸۰ است.
- نتیجهٔ اولیه در API فاقد نمره‌های ابعاد و تحلیل کامل است؛ قفل فقط بصری نیست. ثبت موبایل معتبر ایران و رضایت روشن، گزارش همان ارزیابی را باز می‌کند. ارسال تبلیغات یا SMS اجرا نمی‌شود.
- شماره با ارقام فارسی/عربی و قالب‌های رایج ایران پذیرفته می‌شود؛ در payload عمومی شماره افشا نمی‌شود.
- گزارش کامل: پنج نمودار، مرحله، خلاصه، سه نکته، قوت، فرصت رشد، دلیل، یک اقدام شروع‌محور و سؤال تأملی؛ برنامهٔ کامل اجرایی ارائه نمی‌شود.
- تم از `brandyar-theme` و پیش‌فرض تاریک سایت پیروی می‌کند؛ کلید تغییر تم، منوی موبایل و هدر/فوتر اصلی حفظ شده‌اند.
- قطع اتصال و پاک‌کردن داده‌های اینستاگرام در مسیر عمومی قابل استفاده‌اند؛ نبود تنظیمات Meta مسیر اصلی را متوقف نمی‌کند و وضعیت فنی عمومی نشان نمی‌دهد.
- مدیریت: لید بدون شماره در فهرست، شماره فقط در جزئیات مجاز، جست‌وجوی مجاز شماره، حذف واقعی با نقش و دلیل، بازتولید با مدل سازگار همان ارزیابی.
- بازخورد وضوح سؤال، تجمیع آن در مدیریت و فرم خبره با پنج معیار تناسب، وضوح، نبود قضاوت، نبود ابهام و نبود هم‌پوشانی؛ ذخیرهٔ نسخه‌دار و حسابرسی.
- خروجی عددی ناشناس، آلفای کرونباخ و ماتریس همبستگی داخلی موجود حفظ شده‌اند. این امکانات تأیید روان‌سنجی یا تحلیل عاملی اثبات‌شده نیستند؛ مطالعهٔ تجربی هنوز لازم است.

## migration و ایمنی انتشار

- migrationهای ۱ و ۲ تغییر نکردند. migration شمارهٔ ۳ روی دیتابیس تولید اجرا شد.
- قبل از فعال‌سازی، کد قبلی و پشتیبان سازگار SQLite در محل محدود سرور نگهداری شدند.
- migration در توقف کوتاه سرویس انجام شد؛ سپس فایل‌های آزموده‌شده فعال و سرویس مجدداً active شد.
- `quick_check` و `foreign_key_check` موفق بودند.
- شمار همهٔ جداول قبلی قبل/بعد مقایسه شد: تنها migration، قالب، مدل و ۱۵ سؤال/قواعد/۷۵ گزینهٔ جدید اضافه شدند؛ تعداد داده‌های کاربران، پاسخ‌ها و گزارش‌های قبلی کم نشد.
- hash هر هشت فایل runtime منتشرشده با نسخهٔ آزموده‌شده روی سرور یکسان بود. hash صفحه، JavaScript و CSS نیز با پاسخ HTTPS زنده تطبیق داده شد.
- قالب‌ها، مدل‌ها و گزارش‌های قبلی بازنویسی نشدند؛ ادامهٔ draftهای قدیمی با نسخهٔ خودشان حفظ شده است.

## آزمون‌های انجام‌شده

- ۱۵۴ اجرای تست Python روی سرور انتشار موفق؛ شامل مدل قدیمی و جدید، migration، HTTP، مجوز، مالکیت، CSRF، OAuth با provider آزمایشی، لید، حذف و بازبینی خبره.
- سه مجموعهٔ Node برای رابط جدید، ارزیابی قدیمی و پنل اصلی موفق؛ تست رابط با Node VM است، نه مرورگر.
- syntax JavaScript و `git diff --check` موفق. پروژه HTML/JavaScript استاتیک و Python است؛ bundler یا build تولیدی Node ندارد. آزمون تولیدی روی Python واقعی سرور انجام شد.
- آزمون HTTPS پس از انتشار: سؤال‌های فعال schema3 و متن دقیق، شروع تکراری، پاسخ ناقص و reload، تکمیل پنج مرحله، نمرهٔ واقعی ۷۵ برای پاسخ ۴، نتیجهٔ اولیه بدون ابعاد، منع export پیش از لید، رد شمارهٔ نامعتبر/رضایت ناقص، ثبت شمارهٔ مصنوعی، نمایش پنج بُعد گزارش کامل و الزام تأیید شروع دوباره همگی موفق.
- ارزیابی موقت آزمون زنده، لید مصنوعی، پاسخ‌ها و گزارش‌ها با مسیر رسمی حذف شدند و GET بعدی ۴۰۴ داد. شمارهٔ شخصی واقعی استفاده نشد و پیامکی ارسال نشد.
- آزمون بصری واقعی موبایل/دسکتاپ، مرورگر و تعامل واقعی کلید تم در مرورگر انجام نشده؛ ساختار و رفتار تم با Node و فایل‌ها بررسی شد. این محدودیت نباید به‌عنوان تست بصری موفق گزارش شود.

## موارد وابسته به تنظیم بیرونی و محدودیت‌های واقعی

- هنگام بررسی زنده، تنظیمات Instagram کامل نبود و قابلیت اتصال عمومی مخفی بود. OAuth واقعی با حساب Business/Creator و app review هنوز آزمایش نشده است؛ موفقیت این بخش ادعا نمی‌شود.
- تنظیم امن `META_INSTAGRAM_APP_ID`، `META_INSTAGRAM_APP_SECRET`، `META_INSTAGRAM_REDIRECT_URI`، `META_GRAPH_VERSION` و `PB_TOKEN_ENCRYPTION_KEY` توسط مسئول سرویس لازم است؛ callback باید دقیقاً آدرس رسمی همین سایت باشد. هیچ مقدار محرمانه‌ای در گزارش ذخیره نشده است.
- پیاده‌سازی موجود state یک‌بارمصرف، CSRF، کنترل حساب حرفه‌ای و توکن رمزنگاری‌شدهٔ سرور دارد؛ عدم ثبت query callback در proxy و grant واقعی باید پیش از فعال‌سازی تأیید شوند.
- مقایسهٔ Instagram محدود به دادهٔ رسمی دریافت‌شده، معرفی، تعداد محتوا، قالب و هشتگ‌های واقعی است؛ تحلیل معنایی خودکار هدف/محتوا، کیفیت، شخصیت یا ویژگی حساس تولید نمی‌شود. Instagram نمرهٔ خوداظهاری را دستکاری نمی‌کند.
- حساب دائمی عمومی و بازیابی بین دستگاه‌ها در معماری فعلی موجود نیست؛ بازیابی مهمان به نشست امن ۳۰روزهٔ همان مرورگر وابسته است و با حذف cookie تضمین ندارد.
- refresh خودکار توکن، callback امضاشدهٔ حذف Meta، پاک‌سازی زمان‌بندی‌شده و سیاست حقوقی backup در این انتشار تکمیل نشده‌اند؛ قطع اتصال و حذف درون محصول موجودند.
- اعتبارسنجی روان‌سنجی تجربی هنوز انجام نشده است؛ امکانات جمع‌آوری/بازبینی/تحلیل مقدماتی فراهم شده‌اند، نه ادعای اعتبار قطعی.
