# مسیر کاربر و وضعیت‌های تجربه

## ورود

از دکمه‌های اصلی «ارزیابی رایگان» سایت یا `/personal-brand` وارد شوید؛ مسیر قدیمی `/#/assessment` و مسیر `/assessment` نیز به همین جریان هدایت می‌شوند. صفحه محدودیت علمی و وابستگی دسترسی به همین مرورگر/نشست را توضیح می‌دهد. فهرست واقعی ارزیابی‌ها نمایش داده می‌شود؛ در نبود داده، دعوت به شروع دیده می‌شود. حساب عمومی دائمی و بازیابی بین دستگاه‌ها وجود ندارد.

## پنج مرحله

۱. تخصص کوتاه، وضعیت حرفه‌ای از هشت گزینه، هدف از نه گزینه، مخاطب، مسئله و یک تا دو مانع از ده گزینه. فیلدهای الزامی روشن‌اند.
۲. جملهٔ موردانتظار مخاطب، تمایز روش، مسئلهٔ واحد، مخاطب مناسب/نامناسب و ارزش‌ها. سؤال بیو در این مرحله نیست.
۳. ۲۴ گویهٔ پنج‌درجه‌ای در شش بُعد، چهار گویه برای هر بُعد؛ ترتیب و فعال‌بودن در نسخهٔ قالب ثبت و برای ارزیابی ثابت می‌ماند. گزینهٔ پیش‌انتخاب‌شدهٔ جهت‌دهنده وجود ندارد.
۴. شواهد، موضوع‌ها، مسئله‌ها، محتوای موفق/کمترموفق، لینک HTTPS نمونه‌کار و توضیح تکمیلی؛ همه اختیاری‌اند. لینک فقط ذخیره می‌شود و محتوا از آن خوانده نمی‌شود.
۵. پیشنهاد شفاف Instagram با دو انتخاب هم‌وزن. رضایت جداگانه برای اتصال لازم است؛ ادامه بدون اتصال بدون رضایت و بدون جریمهٔ نمره انجام می‌شود. فقط پس از انتخاب ادامه بدون اتصال، معرفی دستی اختیاری ظاهر می‌شود.

تخصص حداکثر ۲۰۰ و متن‌های دیگر حداکثر ۱۲۰۰ نویسه، شمارنده و escape خروجی دارند. draft هنگام تایپ فقط در sessionStorage همین تب است؛ ثبت قطعی پس از ذخیرهٔ مرحله در سرور انجام می‌شود. نبود storage مرورگر مانع ذخیرهٔ سرور نیست و اطلاع داده می‌شود. بازگشت به مرحلهٔ قبل پاسخ‌های ذخیره‌شده را حفظ می‌کند. revision مانع overwrite ناخواسته توسط تب قدیمی می‌شود.

## مسیر بدون اتصال

پس از انتخاب «ادامه بدون اتصال»، معرفی اختیاری را وارد یا خالی بگذارید و تولید گزارش را بزنید. گزارش با خوداظهاری یا شواهد کاربر تولید می‌شود؛ هیچ پیج یا دادهٔ ساختگی اضافه نمی‌شود.

## مسیر اتصال

checkbox رضایت، سپس ورود به صفحهٔ رسمی Meta. بازگشت با وضعیت اتصال، لغو یا خطا مشخص می‌شود. در موفقیت، همگام‌سازی را اجرا و ارزیابی ذخیره‌شده را باز کنید. فقط با snapshot معتبر و مجوز منقضی‌نشده، ادامه با شواهد پیج ممکن است. account شخصی، نبود config، مجوز ناکافی یا خطای سرویس نباید مسیر بدون اتصال را مسدود کنند.

اگر API بیو را ندهد، در گزارش همین محدودیت نمایش داده می‌شود. وجود مجوز پایه به معنی دریافت insight یا تحلیل کامل نیست. UI وعدهٔ تحلیل معنایی لحن/تصویر/ویدیو نمی‌دهد. مجوز منقضی یا قطع‌شده با درخواست اتصال دوباره مشخص می‌شود.

## گزارش

بلوغ احتمالی، confidence، قوت/گلوگاه نسبی، الگوی احتمالی، شش نمره و تعریف بُعد، پیام مرکزی اولیه، مخاطب/مسئله/تمایز خوداظهاری، سه اقدام فوری و سه اقدام سی‌روزه همراه مبنای توصیه نمایش داده می‌شوند. در صورت اتصال، بیوی در دسترس، تعداد نمونه، نسبت قالب‌ها، هشتگ و شاخص لغوی احتمالی فراخوان اقدام به‌صورت زمینهٔ تکمیلی می‌آیند.

نتیجه و زمان/نسخه ذخیره می‌شوند؛ retry گزارش تکمیل‌شده نسخهٔ تکراری نمی‌سازد. مدیر می‌تواند بازتحلیل نسخه‌دار ایجاد کند؛ دو نتیجهٔ اخیر برای کاربر قابل مقایسه‌اند. دریافت فایل HTML برای اشتراک‌گذاری با اقدام صریح کاربر و audit انجام می‌شود، بدون لینک عمومی یا اجرای متن به‌عنوان کد.

## حالات قابل مشاهده

- بارگذاری: پیام دریافت اولیه، feedback و جلوگیری از ارسال هم‌زمان.
- موفقیت: دادهٔ واقعی از پاسخ API و گزارش ذخیره‌شده.
- بدون داده: ارزیابی/گزارش/اتصال خالی با توضیح و اقدام بعدی.
- خطا: پیام فارسی امن، شناسهٔ پیگیری در API و دکمهٔ بازخوانی.
- دسترسی‌نداشتن: ۴۰۱/۴۰۳ نشست یا مجوز و ۴۰۴ مالکیت رکورد، بدون افشای رکورد دیگر.
- لغو: بازگشت OAuth لغوشده و dialog لغو، بدون ثبت موفقیت جعلی.
- حذف: تأیید checkbox و دکمهٔ نهایی؛ Escape یا تأیید قبلی عملیات تازه را تأیید نمی‌کند.

قطع اتصال جلوی استفادهٔ آینده از token را می‌گیرد. حذف Instagram گزارش مشتق‌شدهٔ دارای پیج را نیز حذف می‌کند، اما پاسخ‌ها و گزارش صرفاً پرسش‌نامه‌ای باقی می‌مانند. حذف ارزیابی، همهٔ داده‌های فرزند آن را پاک می‌کند. گزارش حذف‌شده خروجی خالی امن دارد، نه خطای index یا نتیجهٔ ساختگی.

## پذیرش ظاهری

رابط فارسی/RTL، تاریخ و عدد فارسی، کنترل با برچسب، focus-visible، حداقل ارتفاع لمس ۴۴px، layout تک‌ستونه در موبایل و کاهش حرکت دارد. این قراردادها و رفتار اصلی با تست بدون مرورگر بررسی شده‌اند؛ تست بصری واقعی و مرورگری در این محیط انجام نشده است.
