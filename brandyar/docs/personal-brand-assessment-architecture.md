# معماری ارزیابی ساختاریافتهٔ پرسونال برند

## مرز ماژول

دیتامدل ماژول افزایشی است و قرارداد API قدیمی، داده‌های Supabase و گزارش‌های قبلی حذف نمی‌شوند؛ اما ورودی اصلی سایت و ناوبری ارزیابی پنل اکنون به این ماژول وصل‌اند. `/#/assessment` و `/assessment` به `/personal-brand` هدایت می‌شوند. قالب فعال ۲۴ گویه دارد و migration شمارهٔ ۲ قواعد گویه و تاریخچهٔ اجرای تحلیل را اضافه کرده است. وضعیت انتشار در [گزارش تحویل](personal-brand-assessment-release.md) ثبت شده است.

- صفحهٔ کاربر: `/personal-brand`
- صفحهٔ مدیریت: `/admin/personal-brand`
- API کاربر: `/api/personal-brand`
- API مدیریت: `/api/admin/personal-brand`
- callback: `/api/personal-brand/instagram/callback`
- فایل‌های نمایش: `personal-brand.html`، `personal-brand.css` و `personal-brand.js`
- لایهٔ دامنه و دسترسی: `personal_brand.py`
- سؤال، اعتبارسنجی و محاسبه: `personal_brand_model.py`
- اتصال رسمی: `personal_brand_instagram.py`
- آمار توصیفی: `personal_brand_validation.py`
- نگهداری و بازگشت: `personal_brand_maintenance.py`

## جریان داده

مرورگر ← API هم‌مبدأ HTTPS ← نشست HttpOnly و CSRF ← SQLite با FK فعال.

در اتصال اختیاری: API ← ثبت رضایت و hashِ state ← صفحهٔ رسمی OAuth ← callback یک‌بارمصرف ← تبادل کد روی سرور ← Fernet ← اتصال متعلق به همان نشست. همگام‌سازی فقط برای حساب متصل انجام می‌شود؛ URLهای pagination، لینک نمونه‌کار و رسانهٔ خارجی fetch نمی‌شوند.

گزارش از نسخهٔ تست و مدلِ ثبت‌شده هنگام آغاز ارزیابی ساخته می‌شود. ورودی گزارش شامل snapshot پاسخ‌ها، سؤال‌ها، وزن‌ها و در صورت رضایت، دادهٔ رسمی در دسترس است. هر بازتحلیل یک سطر جدید با دلیل می‌سازد. بازتحلیل مدیریتی می‌تواند مدل منتشرشدهٔ جدید را انتخاب کند، اما سؤال‌های پاسخ‌داده‌شده را به نسخهٔ دیگری منتقل نمی‌کند.

## قرارداد API

GET با `action=bootstrap` یک نشست ۳۰روزه می‌سازد یا داده‌های نشست معتبر را برمی‌گرداند. GET با `id` فقط رکورد متعلق به همان نشست را می‌خواند. پاسخ موفق، `ok`، `data` و `request_id` دارد؛ خطا پیام فارسی و شناسهٔ پیگیری دارد.

POST کاربر: `start`، `save`، `report`، `view_report`، `offer_view`، `abandon`، `export_report`، `oauth`، `sync`، `disconnect`، `delete_instagram`، `delete_assessment`. تمام POSTها CSRF و مبدأ معتبر می‌خواهند. `save` به revision فعلی وابسته است؛ گزارش تکمیل‌شده با retry بازتولید نمی‌شود.

POST مدیر: `template_draft`، `model_draft`، انتشار/غیرفعال‌سازی نسخه، `regenerate`، `archive`، `disconnect_connection`، `privacy`، `feedback`. تأیید نهایی و دلیل الزامی‌اند. GET مدیریت فیلتر، صفحه‌بندی و `validation_export` کنترل‌شده دارد.

## کنترل دسترسی

- مالکیت عمومی به hashِ cookie امن متصل است، نه شناسهٔ دلخواه ارسالی کاربر.
- owner/admin با مجوزهای assessments و private پاسخ و گزارش کامل را می‌بینند؛ analyst فقط فهرست و آمار را می‌بیند.
- عملیات تغییر به publish و assessments نیاز دارد؛ پشتیبان و content_manager این دسترسی را ندارند.
- خروجی پژوهشی فقط با مجوز export و با حذف شناسه، متن آزاد، زمان و دادهٔ پیج قابل دریافت است.
- access token در هیچ DTO عمومی یا مدیریتی وجود ندارد.

## قابلیت اطمینان

SQLite تراکنش کوتاه دارد؛ فراخوانی شبکه خارج از تراکنش نوشتن نگه داشته می‌شود. پیش و پس از پاسخ Meta وضعیت رضایت/اتصال بازبینی می‌شود تا قطع اتصال هم‌زمان بی‌اثر نشود. sync ناموفق دادهٔ موفق قبلی را پاک نمی‌کند. آخرین اجرای sync و خطا ثبت می‌شوند. expiry مجوز، استفادهٔ بعدی از توکن را متوقف می‌کند.

محدودیت‌ها: ۱۰ ارزیابی در ساعت برای نشست؛ ۶۰ عملیات ثبت‌شده در دقیقه برای مالک؛ ۱۲۰ POST در دقیقه برای منبع شبکه؛ ۳۰ نشست تازه در ۱۵ دقیقه برای منبع؛ فاصلهٔ sync یک دقیقه. X-Real-IP فقط از reverse proxy روی loopback پذیرفته می‌شود؛ proxy باید این هدر را بازنویسی کند. در استقرار چند replica این شمارنده‌ها باید در ذخیرهٔ مشترک قرار گیرند.

## وضعیت واقعی و مرزهای باقی‌مانده

موتور گزارش فعلی rule-based است، نه تحلیل زبانی یا تصویری AI. Instagram فقط متن/فرادادهٔ حداکثر ۲۵ محتوای اخیر را اضافه می‌کند. تحلیل لحن، شکاف معنایی هویت و محتوا، کیفیت ویدیو/صدا، insights، کامنت و refresh خودکار پیاده نشده‌اند. این بخش‌ها نباید در محصول فعال یا کامل معرفی شوند.

حساب عمومی دائمی و بازیابی بین دستگاه‌ها وجود ندارد. اشتراک‌گذاری از طریق دریافت فایل HTML انجام می‌شود؛ لینک عمومی ساخته نمی‌شود. آزمون مرورگری و بررسی بصری در این محیط اجرا نشده‌اند؛ تست‌های HTTP و Node VM جایگزین ادعای تست مرورگری نیستند.
